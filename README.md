# 낙하 시뮬레이션 (Drop Simulation)

**모든 것을 피해서 낙하하라**

## 게임 개요

끝없는 하늘에서 추락하는 플레이어. 떨어지는 모든 장애물을 피하며 끝까지 내려가는 것이 목표입니다.

## 게임 목표

- **끝까지 내려간다**: 계속 떨어져서 화면 하단에 도달하기

## 플레이어 조작

| 키 | 기능 |
|---|---|
| **F5** | 시점변환 (1인칭 ↔ 3인칭) |
| **WASD** | 이동 |
| **스페이스바** | 점프 |
| **마우스** | 시점 회전 |
| **좌클릭** | 상호작용 |

## 기술 스택

- **엔진**: Unreal Engine 5.4.4
- **프로토콜**: MCP (Model Context Protocol) via ue-mcp v1.3.7 (5.4.4 패치 적용)
- **주요 플러그인**: ue-mcp-5.4.4-patch

## 프로젝트 구조

```
Drop_Simul/
├── Content/              # 게임 에셋 (캐릭터, 머티리얼, 애니메이션 등)
├── Config/               # 프로젝트 설정
├── Plugins/              # 플러그인
├── Drop_Simul.uproject   # UE 프로젝트 파일
└── README.md             # 이 파일
```

## 개발 참고사항

이 프로젝트는 Claude Code와의 MCP 연동을 통해 자연어로 레벨, 캐릭터, 게임 로직을 편집할 수 있습니다.
